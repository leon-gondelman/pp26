# Solutions

Worked solutions, released session by session once a session is done. The
exercises themselves stay where they were: `labs/` for the lab code, and the
handout PDF under `handouts/`.

| | |
|---|---|
| `s2/queue-on-paper-solutions.pdf` | Part A0, the nine pen-and-paper exercises |
| `s2/python/pqueue.py` | Part A |
| `s2/ocaml/pqueue.ml` | Part C |
| `s2/java/PQueue.java` | Part E |
| `s2/ocaml/homework.ml` | the nine OCaml exercises |

The code files are drop-in replacements for the ones with holes in them, and
they carry more commentary than a solution normally would: the interesting
part of this lab is *why* each version looks the way it does in its language,
so the reasoning is written down beside the code rather than left implicit.
